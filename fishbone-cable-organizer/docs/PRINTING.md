## 文件说明 / Files

推荐导入 STEP 或 STL 并核对尺寸约 144 × 66 × 10 mm。STEP 需要切片软件转换与切片，不能直接作为打印机执行指令。仓库不包含设备绑定的本地 3MF 或 G-code，避免将其他设备的映射和私有元数据带入项目。

Import STEP/STL and slice for the target printer. This repository does not include the local device-bound 3MF or G-code.
