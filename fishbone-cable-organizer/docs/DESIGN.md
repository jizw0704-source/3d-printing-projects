# 设计演进 / Design history

目标是能直接 3D 打印、挂在现有工具墙挂钩上的线缆收纳件。外观简约克制，鱼骨稀疏，尽量不依赖额外配件。

| 版本 | 设计变化 |
| --- | --- |
| V01 | 初步鱼骨轮廓与悬挂方向 |
| V02 | 骨节改为圆润、接近圆柱的截面；保留末端缺口 |
| V03 | 改善单侧末端卡槽入口和容纳区 |
| V04 | 骨节引入浅弧曲率，保留直脊柱 |
| V05 | 平背、根部圆角、卡口接触边优化；增加槽宽小样 |
| V06 | 镜像双端卡槽，尝试分别收住线缆两端；进入完整首件试打印 |

本仓库提供 V06 的完整可编辑 CAD 脚本、模型和图像，旧版本以这份演进记录概述。V06 尚不标为稳定版，待实物反馈后再决定尺寸、卡口和容量是否需要调整。

The design evolved from a flat fishbone outline to rounded curved ribs, a printable flat back and mirrored tail slots. V06 is the first full-body print trial documented here. Earlier revisions are summarized rather than distributed as competing print files.

## 首件反馈后的决定

首件打印完成，用户觉得比预想大一些但使用方便；明确不做紧凑版，保留 V06 几何和尺寸。后续以实际使用反馈决定是否调整。
