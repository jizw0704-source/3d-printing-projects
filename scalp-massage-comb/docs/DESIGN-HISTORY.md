# 设计演进 / Design history

## 设计目标 / Brief

用户希望做一把简约的头部按摩梳。手绘草图确定掌握式轮廓；后续明确要求齿长约 2 cm、齿更稀疏、每齿更圆润，增加贴近头形的弯曲，并让握持部和梳齿自然衔接。

A simple palm-held scalp massage comb, guided by the user's sketch: sparse short teeth, rounded contacts, gentle curvature and a natural grip-tooth transition.

## 收敛过程 / Iteration

| 阶段 / Stage | 决策与结果 / Decision and result |
| --- | --- |
| 早期草稿 | 探索整体比例、短齿、齿间留空和圆润接触端；收敛为五齿、18 mm 齿距、约 20 mm 标称齿长。 |
| 握持和弧度调整 | 增加齿列浅凹、齿身上弯与圆润掌握部，保留背面贴床区域。 |
| 外侧肩台问题 | 用户明确指出左右外轮廓的凸台需要取消；加长厚边的 V10 被否定，不作为打印候选。 |
| V11–V12 | 修整外侧肩部轮廓。V12 作为本次精修的基准，保留 STEP、STL 和原始几何检查记录。仅修外轮廓仍未充分改善正面握持部—齿根衔接。 |
| V13 | 对实际网格的前握持部和五个齿根渐变加权精修；减弱 V 形硬折线，保留齿端、间距、上弯形状及后握持区。用户反馈“比之前的好一些”，随后同意准备试打。 |
| 打印准备 | 慢速 PLA 切片完成，目标设备忙碌，未提交。另一台设备状态未核实；用户决定先暂停打印、整理 GitHub。 |

## V13 的证据 / V13 evidence

- 720,692 个三角面；封闭、法向一致、正体积、单一连通体。
- 约 90.53 × 49.22 × 15.30 mm。
- Y=18 mm 截面为五个独立齿形，最小间隙约 6.44 mm。
- 局部最大曲面位移约 1.019 mm，体积相对 V12 减少约 0.885%。
- 齿部接触区与后握持区双向确定性距离抽样最大约 0.019 mm；不是全表面误差上界。
- 正面与侧面轮廓重叠率分别约 99.105% / 98.878%；这些指标说明整体比例保留程度，不给美观、舒适度或解析曲率连续性打分。

几何数据见 [validation.json](../v13/validation.json)，精修方法见 [V13 构建说明](../v13/README.md)。其中 JSON 是生成时的检查快照，最新试打状态见 [打印准备](PRINT-PREPARATION-V13.md)。

## 发布范围 / Publication scope

本次发布 V13 模型、源码、交互预览、对照图、检查记录和拟真实效果图，以及复现所需的 V12 基准模型。更早的工作草稿留在本地，演进决策记录在本页。没有删除本地旧版本。

V13 是网格精修，无对应 STEP；V12 STEP 仅是历史基准。图片使用实际 V13 STL 在本地 Blender 中渲染，均非实物照片。实物试打和触感反馈待后续补充。
